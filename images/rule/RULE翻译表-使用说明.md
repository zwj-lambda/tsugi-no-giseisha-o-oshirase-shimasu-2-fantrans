# RULE 翻译表使用说明(2026-09-17)

本表供在外部工具(Excel / LibreOffice Calc / 文本编辑器 / 外部翻译)
完成翻译后交回, 由管线直接合并进 RULE_PAGES 并重新出效果图。

## 文件

- `RULE翻译表.csv`: 工作表本体(UTF-8 带 BOM)。
- 各页解码原图: 本目录 `RULE*.MPB.png`(2x)。
- 当前译文的并排效果图: `../rule_preview/RULE*.png`。

## 列说明

| 列 | 用途 |
|----|------|
| 页名 | PSPFS 条目名(RULE01-10, 12-18) |
| 块 | 回填键: body=横幅正文, labelN=需重绘的标注, keepN=同形保留标注 |
| 类型 | 正文 / 标注 / 引用框 / 同形标注 |
| 原文(日文) | 页面逐字转录; ` / ` 表示图内一次换行 |
| 现行译文 | 当前 RULE_PAGES 采用的译文(可作参考或底稿) |
| 你的译文 | **只填此列**; 留空 = 沿用现行译文 |
| 说明 | 在图中的位置与备注 |

## 填写规则

1. 只改「你的译文」列, 勿改页名/块(回填按键匹配)。
2. ` / ` 表示图内一次换行; 可自行用它断行, 也可不写交由管线按横幅
   宽度自动换行。
3. 「同形标注」行: 原文与繁体中文同形(指名/生存/死亡/8分/自由時間/
   警官/市民/市民全員死亡), 目前保留游戏原像素; 若想改译, 填入后
   回填时会改为重绘。
4. 同页多处相同标注(如 指名 x3)合并为一行, 回填时全部替换。
5. 保存为 UTF-8; 文件名可改, 交回时告知路径即可。
6. 术语已冻结的以 `../trans/glossary/glossary.json` 为准(連環殺手/
   手環/身分/規則/偵探/指名 等)。

## 范围与边界

- RULE01-10, 12-18 共 17 页。
- RULE00 纯英文模板无需汉化; RULE11 为 32bpp codec 0xa6 未解码页,
  暂无法回写, 不在表内。
- TUTORIAL00/01/10/11 与 NAME00 属后续切片, 届时另出工作表。

## 交回后的流程

合并 RULE_PAGES -> 重新生成 17 页效果图 -> 验收 -> 通过后才写 ISO。
