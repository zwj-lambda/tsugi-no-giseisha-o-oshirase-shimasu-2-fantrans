## 验证顺序(由风险驱动, P7 校对期发现的三大风险优先)

### 1. 首启冒烟(最高优先: 任何崩溃都会在此暴露)
1. PPSSPP 加载 ISO → 标题画面 → 开新档。
2. 序章主线对话滚动读数屏(>10 屏), 确认: 中文正常显示、无蓝屏
   (Invalid Memory Access)、无乱码/空窗。
3. 中途存档 → 读档 → 继续推进(存档元数据不涉文本堆, 但需确认)。

### 2. 标签串匹配风险(ターン→回合 已入标签)
全片 KW/ROM2 标签行内 ターン 已译为 回合(含 kw_vote seq19 的 PUA 前缀行
「鴻2_KW_投票_美紀_回合2」)。若引擎按字符串匹配标签(关键词登记/话题跳转),
实机会在此暴露。
1. 侦探模式: 进入关键词界面, 确认词条登记与跳转正常。
2. 话题跳转: 章节推进至回合切换处(ROM2_回合N 标签行), 确认场景切换不卡死。
3. 异常回退: 按 anchor 显式清单回退标签行到原文形(blocks CSV orig 列;
   注意 kw_vote seq8/10/19 含 PUA 的行 role=narrative, 不能按 role=label 过滤),
   重跑 patch-iso。

### 3. 扩展区字形渲染风险
全库译文含 13 个仅 CP932 扩展区可编码字符: 薰(229) 黑(15) 厲(14) 賴(12) 增(5)
悅(3) 惕(2) 寬(2) 閒(2) 橫(2) 德(1) 炫(1) 綠(1)。扩展区渲染从未实测。
1. 找含 薰/黑 的对话段(如 r2_t2_4_4_0 seq36 附近「紅春」场面、任何 樫澤×薰
   对话), 确认字形显示无缺字/豆腐块。
2. 若缺字, 回退方案: 薰→薫(标准区 8c4f)、黑→黒(8d95) 等日文形, 其余按字定夺,
   做版本内替换表(全库批量, 独立切片)。
3. 同批: 横(标准区)与 橫(扩展区) 并存, 扩展区失败则 2 处 橫 一并归日文形。

### 4. flag/断言串一致性风险
flag 前缀串(`"f_` 族, 如 r2_t4_4_1_0 seq10「報告"f_美紀投票無人提名?」)已按
先例翻译; 若引擎按字符串匹配 flag, 分支会失配。
1. 推进至立 death flag 的剧情分支点, 观察分支是否正常触发。
2. 异常回退: 相关行按原文形回退(kind=binary 行本就未动, 即基准形态),
   重跑 patch-iso。

### 5. 全块类型走查(每种块至少进一次)
| 块类型 | 入口 | 检查点 |
|---|---|---|
| scenario(30) | 主线推进 | 对话/选项/回合切换 |
| keywords(29) | 侦探模式关键词 | 词条显示/跳转 |
| check_*(14) | 角色档案页 | 共享句、图片路径引用正常(未动) |
| game_over/d00 | 死亡演出/番外 | 系统句已译部分显示正常 |
| sts_deb* | 调试遗留(未全译) | 不触发即可 |

## 通过标准

1. 冒烟 + 关键词/话题跳转 + 扩展区字形 + flag 分支全部正常 → P8 完成,
   进入 P9(图片文字)。
2. 仅某类行异常 → 按 2/3/4 的回退方案处理该类行, 重打重验。
3. 全面崩溃(复现一阶段前的蓝屏) → 不应发生(等长模式已定案); 若发生,
   保留现场并用 verify 比对 STS.DAT 与 STS.DAT.new 是否一致后上报。
