# 《死亡通告2》PSP 繁体汉化 · 协作仓库

本仓库是 PSP 游戏《给下一个牺牲者的死亡通告2》(ULJM-05947) 粉丝汉化项目的**协作工作面**，
收录需要修改后回注游戏文件的全部翻译素材：主文本、系统文本、图片文字，
以及配套的术语表、风格指南与审核页。欢迎参与校对译文、改进图片文字翻译。

游戏本体、解包工具与任何可运行的游戏资产**不在本仓库范围内**。

## 翻译目标与硬约束

**翻译目标：繁体字形 + 大陆词汇表达**（词汇用大陆普通话习惯，如 信息/網絡/軟件，不跟台湾特有词 資訊/網路/軟體）。

文本以 CP932（JIS X 0208）编码存储与渲染，游戏字集内基本没有简体字形，因此有四条硬约束：

1. 译文任意字符必须可 CP932 编码——大部分简体字形（门/见/说/为…）不可编码，需改用繁体或 JIS 同形字；
2. **等长槽位**：译文 CP932 字节数不得超过原文（全角字符 2 字节、半角 1 字节）；
3. 行首控制标记（如 `ka_1_`、`.st` 等首个非 ASCII 字符前的 ASCII 前缀）必须原样保留；
4. `role=command` 行（全角片假名引擎指令串）永不翻译，保持原文。

提交前请运行自检：

```bash
python tools/check_csv.py                                  # 检查默认全部范围
python tools/check_csv.py blocks/scenario/r2_t1_1_0.csv    # 检查单个文件
```
